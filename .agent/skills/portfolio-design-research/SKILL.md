# Portfolio Design Research

## Objective

Find a visual direction that feels authored by a designer and appropriate for a full-stack developer with backend, systems, API, data, and blockchain projects.

## Inputs

Read:
- `references/RESUME_CONTENT.md`
- `references/DESIGN_DIRECTION.md`

## Workflow

1. Research 8 to 12 current portfolio or editorial website references when web access is available.
2. Start from curated sources such as:
   - Awwwards portfolio collections
   - SiteInspire
   - Typewolf portfolio collections
   - One Page Love
   - Godly
   - Codrops
3. Search by design characteristics, not by copying a named site:
   - technical editorial portfolio
   - Swiss-modernist web portfolio
   - asymmetric project archive
   - typography-led developer portfolio
   - engineering case study website
4. Select at least five relevant references.
5. For each reference, record only:
   - URL
   - What is useful
   - What should not be copied
6. Derive a new direction by combining separate ideas:
   - One reference for typography
   - One for project indexing
   - One for spacing and grid
   - One for interaction
   - One for mobile behavior
7. Write the synthesis to `DESIGN_NOTES.md`.
8. Define:
   - Design thesis
   - Visual keywords
   - Grid
   - Type system
   - Color logic
   - Section rhythm
   - Project presentation
   - Motion behavior
   - Mobile adaptation
9. Explicitly list rejected generic patterns.
10. Only then start implementation.

## Guardrails

- Never reproduce a reference page.
- Never take a complete color, type, and layout system from one source.
- Never use an image or asset without permission or a valid license.
- Never invent research results when browsing is unavailable.
- When browsing is unavailable, state that in `DESIGN_NOTES.md` and use the supplied design direction as the fallback.
- Prefer design systems that support the content rather than hiding weak content behind effects.

## Output Standard

The research is successful when another designer can read `DESIGN_NOTES.md` and understand why every major visual decision exists.
