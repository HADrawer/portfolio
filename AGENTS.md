# AGENTS.md

## Mission

Build a distinctive, recruitment-focused portfolio for Hashem Ahmed Alkhaldy using semantic HTML, modern CSS, and small amounts of vanilla JavaScript.

## Required Reading

Before planning or editing, read:
1. `references/RESUME_CONTENT.md`
2. `references/DESIGN_DIRECTION.md`
3. `references/QA_CHECKLIST.md`
4. Applicable skills under `skills/`

Treat the resume reference as the only source of truth for personal claims.

## Core Rules

- Use HTML, CSS, and vanilla JavaScript only.
- Do not introduce React, Vue, Tailwind, Bootstrap, component libraries, or a build framework.
- Do not fabricate content, metrics, links, employers, dates, roles, or achievements.
- Do not imitate a single website.
- Research references before implementation when browsing is available.
- Record the research synthesis and design rationale in `DESIGN_NOTES.md`.
- Use the technical editorial direction in `references/DESIGN_DIRECTION.md`.
- Avoid generic AI website patterns.
- Prioritize recruiter scanability, accessibility, performance, and technical credibility.
- Keep JavaScript optional and progressive.
- Ensure the site works from a simple static server and can be deployed to GitHub Pages.

## Expected Structure

At minimum:
- `index.html`
- `styles.css`
- `script.js`
- `assets/`
- `README.md`
- `DESIGN_NOTES.md`

Create additional project detail pages only when they materially improve the result.

## Validation

Run or perform:
- HTML validation
- Keyboard navigation review
- Responsive checks at common widths
- Reduced-motion check
- Broken-link check
- Console-error check
- Content review against the resume source
- Final review against `references/QA_CHECKLIST.md`

A task is not complete merely because the page renders. It is complete when the design is intentional, the content is truthful, and the site is usable.
