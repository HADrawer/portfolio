# Hashem Alkhaldy — Portfolio

Single-page personal site. No framework, no build step.

- `index.html` — the whole site, EN/AR via `script.js`
- `styles.css` — light + dark theme, responsive
- `resume.html` — CV download page
- `assets/images/profile.jpg` — portrait
- `assets/resume/Hashem_Alkhaldy_CV.pdf` — CV

Preview: `python -m http.server` in this folder.
Live: https://hadrawer.github.io/portfolio/
