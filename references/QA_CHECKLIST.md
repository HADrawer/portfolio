# Portfolio Quality Checklist

## Truthfulness
- [ ] Every personal fact is supported by references/RESUME_CONTENT.md.
- [ ] No fabricated numbers, users, revenue, performance gains, clients, awards, or outcomes.
- [ ] Team contributions are not presented as solo work.
- [ ] Missing repository and demo URLs are omitted or marked clearly for the owner to add.

## Design Originality
- [ ] No purple or blue gradient hero.
- [ ] No glowing blobs.
- [ ] No glassmorphism.
- [ ] No card grid used as the main layout.
- [ ] No generic centered hero with floating technology icons.
- [ ] No copied layout from a single reference.
- [ ] At least three references influenced different aspects of the design.
- [ ] The final direction has a written rationale.

## Content
- [ ] Strongest four projects are featured.
- [ ] Each featured project explains the problem and personal contribution.
- [ ] Skills are grouped by system layer.
- [ ] Experience and education are concise.
- [ ] Contact actions work.
- [ ] Resume download works when a resume file is present.

## HTML
- [ ] Semantic landmarks are used.
- [ ] Heading order is valid.
- [ ] Buttons and links use correct elements.
- [ ] External links are labeled clearly.
- [ ] Decorative SVGs are hidden from assistive technology.

## CSS
- [ ] Mobile-first structure.
- [ ] Fluid type uses clamp where appropriate.
- [ ] Focus states are visible.
- [ ] Contrast is accessible.
- [ ] Layout does not depend on fixed viewport heights.
- [ ] No horizontal overflow at 320px.
- [ ] Reduced motion is supported.
- [ ] Print styles produce a clean page.

## JavaScript
- [ ] JavaScript enhances rather than blocks the page.
- [ ] Navigation works without JavaScript where possible.
- [ ] No heavy dependencies.
- [ ] No console errors.
- [ ] Interactions are keyboard accessible.
- [ ] Motion is disabled or reduced when requested.

## Performance
- [ ] No unnecessary framework.
- [ ] Images are optimized.
- [ ] Fonts are limited and loaded efficiently.
- [ ] Layout shift is minimized.
- [ ] Page remains usable on a slow connection.

## Final Review
- [ ] Test at 320px, 375px, 768px, 1024px, and 1440px.
- [ ] Test keyboard-only navigation.
- [ ] Test light and dark system preferences if both are supported.
- [ ] Test with JavaScript disabled.
- [ ] Test with reduced motion enabled.
- [ ] Proofread every sentence.
